# Smart Travel Planner (AirFly Insights)

## Overview
Smart Travel Planner is a production-ready Streamlit dashboard for airline delay analytics, prediction, and data-driven planning.

It provides:
- Overview of operations KPIs
- Analysis of airline and airport delay trends
- ML-based delay risk prediction
- Smart Planner recommendations (best month/airline and high-risk airlines)
- autogenerated insights and interactive charts

## Setup
1. Create and activate virtual environment:
   - `python -m venv venv`
   - `venv\Scripts\activate` (Windows) or `source venv/bin/activate` (Linux/Mac)
2. Install dependencies:
   - `pip install -r requirements.txt`
3. Run app:
   - `streamlit run app.py`
4. Open in browser:
   - `http://localhost:8501`

## Configuration
- `.streamlit/config.toml` (theme + server settings)
- `runtime.txt` (Python version)

## Data
- `airline_operations.csv` should be placed in same folder as `app.py`.

## Requirements
- `streamlit`
- `pandas`
- `numpy`
- `scikit-learn`
- `plotly`
- `seaborn`
- `pydeck`
- `fpdf` (optional)

## Deployment
Use Streamlit Cloud, Heroku, or Docker:
- Streamlit Cloud: push GitHub repo, connect in UI; starts on `share.streamlit.io`
- Heroku: `Procfile` and `git push heroku main`
- Docker: `docker build -t smart-travel-planner .` and `docker run -p 8501:8501 smart-travel-planner`

## Best practices
- Keep `airline_operations.csv` up-to-date
- Use cache decorators for speed (`@st.cache_data` already used)
- Add exception handling for missing data

## Notes
- Prediction uses linear regression and risk thresholds
- Smart Planner section includes low/medium/high risk classification
- Insights section automatically generates key data nuggets
